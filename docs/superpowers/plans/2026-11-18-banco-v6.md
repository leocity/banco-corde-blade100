## Contratto dei dati (condiviso tra pipeline e pagina)

Ogni corda in `data/strings.json` → `strings[i].lab`:
```json
{
  "twu":   {"stiffness": 217.4, "loss": 44.1, "spin": 8.1, "ref_lbs": 51, "date": "2026-10-28", "url": "https://twu.tennis-warehouse.com/learning_center/reporter2.php"},
  "rp":    {"kgmm": 0.75, "date": "2026-10-28", "url": "<scheda Racketpedia>"},
  "excel": {"stretch50": 3.289, "recover50": 0.533, "creep24": 1.2, "date": "2026-08-26"}
}
```
- `twu` solo se `twu.match == "exact"`; singoli campi null se mancano. `rp` solo se `rpedia.match == "exact"` e kg/mm presente. `excel` solo se esiste la riga Excel; `stretch50 = stretch_pct["50"]`, `recover50 = recover_pct["50"]`, `creep24 = static_24h_creep` (null se assente).
- Date: da `data/raw/sources.json` (provenance v3) se presente, altrimenti la data del file.
- Radice: `lab_meta = {"excel_stretch50_sd": <dev. std. del campione Excel>, "n": {"twu": 55, "rp": 48, "excel": 44}}`.
- `defaults`: `equipped = {"id": "re-string-slap-17", "kg": [22, 21]}`, `liked = [confidential-16l, o-toro-17, zero-17, slap-17]`, `disliked = [conf-soft-16, -17, -16l, rpm-blast-16, -17, barb-wire-16]` (solo id esistenti).
